## Install

The most convenient way to integrate the `@micro-os-plus/diag-trace`
package into a project is to add it as a dependency via **xpm**.

<CodeBlock language="console"> {
`xpm install @micro-os-plus/diag-trace@${frontMatter.version} -verbose
`} </CodeBlock>

Comprehensive instructions can be found in the [Install Guide](/docs/install/).
